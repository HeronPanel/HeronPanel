# ?? HeronPanel

**HeronPanel** is a premium, professional game server management panel designed with a high-performance "SNOW" design language. It provides full orchestration of game servers using a hybrid approach of native Linux processes and Docker containers.

## ?? Features
- **Distributed Architecture**: Central API with high-performance Go-based Daemons.
- **Hybrid Engine**: Support for both standard Linux processes and Docker containers.
- **Minecraft Specialist**: Integrated installation pipeline for Vanilla, Paper, and Fabric.
- **Real-time Control**: WebSocket-powered live consoles and system monitoring.
- **Enterprise Ready**: RBAC (Owner/Admin/User), Audit Logging, and Secure API-Key handshake.
- **Management Suite**: Integrated File Manager, Database Manager, and Backup System.

## ?? Tech Stack
- **Frontend**: Next.js 14, Tailwind CSS, Shadcn UI, Framer Motion.
- **Backend**: Node.js (Fastify), TypeScript, Prisma ORM, PostgreSQL.
- **Agent**: Go (Golang), Docker SDK.
- **Real-time**: Socket.io.
